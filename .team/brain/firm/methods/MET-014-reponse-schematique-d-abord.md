# Réponse schématique d'abord (machine)
usage: toute analyse en conversation ou en livrable (§4.17, §7.1). Exception : réponse courte = deux ou trois phrases, sans titre ni puces (§7.2).

## Choisir la forme
| besoin | forme |
| comparer des options, cantons, variantes | tableau (options en colonnes, critères en lignes, recommandation surlignée) |
| faits et délais | chronologie (date · événement · source · conséquence) |
| conditions successives | arbre de décision (oui/non, feuilles = conséquence + niveau de confort) |
| structure de groupe, participations, organes | organigramme (pourcentages, ayants droit, sources registre) |
| procédure, statut d'un dossier | machine à états (étapes, déclencheurs, délais) |
| acteurs | carte des parties prenantes (MET parties prenantes) |
| succession, famille | arbre familial (régime, réservataires) |
| chiffres dans le temps | graphique avec message, unité, source (visualiseur) |

## Étapes
1 identifier la question que le lecteur se pose · 2 choisir une seule forme principale · 3 la construire avec sources et niveaux de confort dans les cellules · 4 texte : ce que le schéma ne dit pas (motivation, réserves, suites) · 5 conversation : markdown simple (tableau ≤ 7 lignes) ; document : visualiseur → fichier (Mermaid/draw.io/PNG) via deliverable-production

## Contrôle
[ ] forme adaptée au besoin · [ ] lisible sans le texte · [ ] sources et dates dans le schéma · [ ] motivation présente quand elle compte · [ ] pas de tableau pour une réponse d'une phrase

## Pièges
tableau décoratif qui répète le texte · schéma sans source · trop de colonnes · arbre sans feuilles conclusives · oublier la phrase de réponse au-dessus du tableau.

## Exemple (court)
« Vous pouvez distribuer, mais pas avant l'AG. »
| étape | quand | qui | source |
| comptes 2026 approuvés par l'AG | ≤ 6 mois après clôture ⚠ | AG | CO (à lire) |
| décision de dividende | même AG | AG | PV |
| impôt anticipé déclaré et versé | délai dès échéance (horloge) | société | LIA (à lire) |
