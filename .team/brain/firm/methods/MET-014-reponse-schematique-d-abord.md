# Schematic answer first (machine)
use: any analysis in conversation or deliverable (§4.17, §7.1). Exception: short answer = two or three sentences, no title or bullets (§7.2).

## Choose the form
| need | form |
| compare options, cantons, variants | table (options in columns, criteria in rows, recommendation highlighted) |
| facts and deadlines | timeline (date · event · source · consequence) |
| successive conditions | decision tree (yes/no, leaves = consequence + comfort level) |
| group structure, holdings, organs | org chart (percentages, ayants droit, register sources) |
| procedure, status of a matter | state machine (stages, triggers, deadlines) |
| actors | stakeholder map (MET stakeholders) |
| succession, family | family tree (regime, réservataires) |
| figures over time | chart with message, unit, source (visualiser) |

## Steps
1 identify the question the reader is asking · 2 choose one single main form · 3 build it with sources and comfort levels in the cells · 4 text: what the diagram does not say (reasoning, reservations, follow-up) · 5 conversation: simple markdown (table ≤ 7 rows); document: visualiser → file (Mermaid/draw.io/PNG) via deliverable-production

## Checks
[ ] form suited to the need · [ ] readable without the text · [ ] sources and dates in the diagram · [ ] reasoning present when it matters · [ ] no table for a one-sentence answer

## Pitfalls
decorative table repeating the text · diagram without source · too many columns · tree without conclusive leaves · forgetting the answer sentence above the table.

## Example (short)
« Vous pouvez distribuer, mais pas avant l'AG. »

| impôt anticipé déclaré et versé | délai dès échéance (horloge) | société | LIA (à lire) |
